How the score is computed

This prototype

Runs entirely in your browser. For each niche factor it aligns your ortholog to a reference and derives an interface sequence-identity value (the X1 axis — the cheapest, fastest feature in the pipeline). Each ligand–receptor pair is scored by its limiting identity against an empirically-set compatibility floor; pairs below the floor are flagged as bottlenecks.

The bundled reference panel is illustrative. The zebrafish example uses the real precomputed X1 values from the training set.

The full pipeline

Production scoring calls the Python backend, which computes all five feature axes — sequence (X1), structure (X2), docking energetics (X3), biophysical (X4) and evolutionary context (X5) — collapses redundant features by covariance, and feeds them to the importance-weighted ordinal Frank–Hall classifier trained across ICH, ICM and WEN media.

Swap the client scorer for a call to POST /api/score to run the trained model. See backend/ in the repo.
